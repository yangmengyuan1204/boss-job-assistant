3. 每个模块的职责说明

3.1 src/boss_tool/

模块职责
__init__.py包标识，仅暴露 __version__ = "0.1.0"。
__main__.py支持 python -m boss_tool 调用，转调 cli.app()。
cli.pyTyper CLI 入口。提供 doctor/init-db/show-config 真实命令，run/resume/export 预留命令。doctor 检查 Python 版本、配置加载、数据/日志/输出目录可写、user_data 可创建、SQLite 可初始化、Playwright 包是否安装（不启动浏览器、不访问网络）。show-config 对敏感字段脱敏。
config.pyYAML+Pydantic v2 配置加载与校验。定义 11 个配置模型（AppConfig / BrowserConfig / RuntimeConfig / BudgetConfig / PageIntervalConfig / RevisitConfig / DatabaseConfig / LoggingConfig / LocationConfig / KeywordConfig / ScoringConfig）。强制红线校验：headless=false、single_context=true、single_account=true、allow_unattended=false、allow_background=false、require_user_confirm=true、min_seconds<=max_seconds、所有预算 >0、评分权重和=100。extra="forbid" 拒绝未知字段。
enums.py所有枚举集中定义（15 个）：AgeTargetCategory / AgeMatchCategory / BoundaryRisk / Confidence / PhysicalIntensityCategory / WalkingIntensity / ShiftType / ActivityCategory / HiringLikelihood / JobActiveState / JobStatus / SkipReason / StopReason / SalaryUnit / RunStatus。包含 AGE_TARGET_TO_MATCH 映射表。继承 str+Enum 便于序列化。
logging_config.py标准库 logging + RotatingFileHandler。控制台+文件双输出。_RedactFilter 对 13 类敏感关键字（cookie/api_key/captcha/verify_code 等）自动脱敏。防重复添加 Handler。

3.2 src/boss_tool/models/

模型职责
job.py / Job岗位主表模型。28+ 字段：标识、薪资、经验学历、描述、地址、时间状态、年龄结果（嵌入）、劳动强度结果（嵌入）、招聘者信息（嵌入）、缓存去重、采集元、评分与优先级。薪资区间校验、URL 非空校验。
age.py / AgeResult年龄目标判定结果。9 条一致性校验：age_target_category 与 age_match_category 必须映射一致；exact_65_cap 必须 is_exact_65_cap=True 且 eligible；非 exact_65_cap 不得 is_exact_65_cap=True；rejects_60 必须 accepts_candidate_age=False 且 age_needs_review=False；boundary_60 必须 age_needs_review=True 且 accepts_candidate_age=None 且 boundary_risk=high；no_explicit_age 必须 age_needs_review=True；eligible 三类必须 accepts_candidate_age=True 且 age_needs_review=False；age_min<=age_max。
physical.py / PhysicalIntensityResult劳动强度判定结果。17 项证据字段（sitting_allowed / prolonged_standing / patrol_required / walking_intensity / stair_climbing_required / lifting_required / lifting_weight_text / garbage_transport_required / outdoor_work / high_temperature_exposure / work_area_text / shift_type / night_shift_required / working_hours_text / rest_schedule_text 等）。physical_intensity_score 限制 0-100。
recruiter.py / RecruiterInfo招聘者公开信息。仅采集公开可见字段：name / title / activity_raw / activity_category / active_within_3d。
collection.py / CollectionMeta采集元信息。含缓存与去重字段：visited_jobs / last_detail_visit_at / detail_content_hash / skip_reason / revisit_allowed_at / list_stage_passed / detail_visit_count。
run.py / RunRecord单次运行记录。账号健康记录字段（account_warning_detected / warning_type / warning_text）+ 运行统计字段（page_count / detail_page_count / search_page_count / cache_hit_count / duplicate_skip_count / list_filter_skip_count / run_duration_seconds / consecutive_errors / stopped_by_safety_rule / user_aborted / last_successful_url）。

3.3 src/boss_tool/storage/

模块职责
database.pySQLite 数据库封装。使用标准库 sqlite3，不引入 ORM。提供 connect() / close() / initialize()（幂等）/ transaction() 上下文管理器（异常自动回滚）/ commit() / get_schema_version()。打开 PRAGMA foreign_keys = ON。所有 SQL 参数化。
migrations.py迁移入口占位。返回当前可用迁移版本号 [1]。未来 v2+ 迁移注册到 database._MIGRATIONS。
repositories.py4 个 Repository：
  • JobRepository：upsert()（INSERT ON CONFLICT 更新）/ get_by_id() / get_by_url()。
  • CollectionMetaRepository：create()。
  • RunLogRepository：create() / finish()。
  • GeocodeCacheRepository：upsert() / get()。
所有方法不自动 commit，由调用方通过 Database.transaction() 或显式 db.commit() 提交，确保事务正确回滚。

def _load_config_safe(config_dir: Path | None):
    """加载配置，失败时抛 typer.Exit。"""

        return load_config(config_dir or _default_config_dir())
    except FileNotFoundError as e:
        typer.echo(f"[ERROR] 配置加载失败: {e}", err=True)
        raise typer.Exit(code=2) from e
    except Exception as e:  # noqa: BLE001 - 配置校验错误统一处理
        typer.echo(f"[ERROR] 配置校验失败: {e}", err=True)
        raise typer.Exit(code=2) from e

    log_cfg = cfg["app"].logging
    logs_dir = cfg["app"].logs_dir
