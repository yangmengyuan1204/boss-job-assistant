# BOSS 直聘岗位辅助工具 · 使用说明

面向 60 岁求职者（保洁、保安、物业等岗位）的离线岗位报告生成工具。

---

## 一、环境准备

### 1.1 安装 Python

需要 Python 3.10 或更高版本（推荐 Python 3.11）。

检查已安装版本：

```
python --version
```

如果版本低于 3.10，请从 https://www.python.org/downloads/ 下载并安装。

### 1.2 安装依赖

在项目根目录执行：

```
python -m pip install -e ".[dev]"
```

### 1.3 初始化数据库

首次使用前需初始化 SQLite 数据库：

```
python -m boss_tool init-db
```

---

## 二、采集岗位数据

报告依赖已采集的岗位数据。采集流程为：

1. **浏览器登录**：`python -m boss_tool browser-login`
2. **观察搜索结果页**：`python -m boss_tool observe-page`
3. **采集当前列表页**：`python -m boss_tool collect-current-page`
4. **采集当前详情页**：`python -m boss_tool collect`（需先在浏览器中手动打开详情页）

> **重要安全规则**：
> - 全程使用 Playwright 可见浏览器，不得后台静默运行
> - 遇到验证码、滑块、登录失败、403/429 等情况立即停止
> - 不得实现反检测、绕过风控等功能
> - 所有操作预算写入配置文件，不硬编码

---

## 三、生成 HTML 报告

### 3.1 基本用法

```
python -m boss_tool generate-report
```

默认从 `data/boss.db` 读取数据，输出到 `output/report.html`。

### 3.2 常用选项

| 选项 | 说明 | 示例 |
|------|------|------|
| `--output, -o` | 指定输出文件路径 | `--output D:\reports\job.html` |
| `--config-dir, -c` | 指定配置目录 | `--config-dir config` |
| `--db-path` | 指定数据库路径 | `--db-path D:\data\boss.db` |
| `--open` | 生成后自动用浏览器打开 | `--open` |

### 3.3 完整示例

```
python -m boss_tool generate-report --open
```

生成报告后自动在浏览器中打开（仅打开本地文件，不访问任何在线页面）。

### 3.4 安全保证

- **只读 SQLite**：使用 `mode=ro` 只读连接，不执行任何写操作
- **完全离线**：不访问网络，不依赖 LLM 或机器学习
- **XSS 防护**：所有动态内容经 `html.escape` 转义
- **URL 校验**：所有链接经 `sanitize_url` 校验，仅允许 BOSS 直聘官方 HTTPS 链接
- **无外部资源**：内联 CSS/JS，不依赖 CDN、字体或图片

## 四、阅读报告

### 4.1 报告结构

报告分为四个分区，按推荐程度从高到低排列：

| 分区 | 颜色 | 含义 |
|------|------|------|
| 强烈推荐 | 绿色 | 适合 60 岁 + 3 公里内 + A/B 等级 |
| 可考虑 | 蓝色 | 适合 60 岁但距离/评分稍低 |
| 待人工确认 | 黄色 | 年龄未知或需进一步确认 |
| 不符合 | 红色 | 不适合 60 岁或明确超出 3 公里 |

### 4.2 排序规则

岗位按以下 7 级优先级排序（从高到低）：

1. 年龄适配（适合 > 需确认 > 未知 > 不适合）
2. 3 公里内（是 > 未知 > 否）
3. 推荐等级（A > B > C > D）
4. 总分（高 > 低）
5. 距离（近 > 远）
6. 招聘者活跃度（3 日内 > 本周 > 较久 > 不活跃）
7. 采集时间（新 > 旧）

### 4.3 筛选功能

报告顶部提供筛选控件：

- **关键词搜索**：输入标题、公司、地点等关键词筛选
- **分区筛选**：下拉选择只显示某个分区
- **重置按钮**：清除所有筛选条件

### 4.4 年龄适配说明

| 标签 | 含义 |
|------|------|
| 适合 60 岁 | 岗位无年龄限制或上限 ≥65 岁 |
| 需人工确认 | 年龄上限 60 岁（边界情况）或其他需确认情况 |
| 不适合 60 岁 | 年龄上限 <60 岁（如 45/50/55 岁以下） |
| 年龄未知 | 未提取到年龄要求，建议联系招聘者确认 |

## 五、已知限制

1. **岗位实时性**：报告中的岗位可能已关闭或招满，需联系招聘者确认
2. **年龄判断**：基于文本提取，不保证 100% 准确，边界情况需人工确认
3. **距离计算**：依赖 P5 地理编码结果，部分地址可能无法解析
4. **数据完整性**：部分岗位可能缺少详情页数据（仅列表页信息）
5. **单账号单浏览器**：不支持多账号或多浏览器并行采集
6. **不自动投递**：本工具不替用户自动投递简历或联系招聘者
7. **不承诺永不封号**：操作预算仅作为参考，不保证不触发平台风控

## 六、故障排查

### 6.1 数据库文件不存在

```
[ERROR] 数据库文件不存在: data/boss.db
```

解决：先执行 `python -m boss_tool init-db` 初始化数据库，并完成岗位采集。

### 6.2 配置加载失败

```
[WARN] 配置加载失败，降级使用默认常量
```

解决：报告生成不依赖配置，会使用默认常量（参考地点：杭州市拱墅区锦园小区，距离阈值：3 公里，候选人年龄：60 岁）。如需自定义配置，请检查 `config/` 目录。

### 6.3 报告为空

```
[WARN] 数据库无岗位记录，将生成空报告
```

解决：先通过采集流程（observe-page → collect-current-page → collect）将岗位数据写入数据库。
