# BOSS 直聘岗位辅助工具 · 使用说明

面向 60 岁求职者（保洁、保安、物业等岗位）的离线岗位报告生成工具。

---

## 一、环境准备

### 1.1 安装 Python

需要 Python 3.10 或更高版本（推荐 Python 3.11）。

检查已安装版本：

```
python --version
```

如果版本低于 3.10，请从 https://www.python.org/downloads/ 下载并安装。

### 1.2 安装依赖

在项目根目录执行：

```
python -m pip install -e ".[dev]"
```

### 1.3 安装 Playwright 浏览器内核

```
python -m playwright install chromium
```

该命令下载可见浏览器内核，供 `browser-login`、`observe-page`、`collect-current-page` 使用。
`generate-report` 命令不需要浏览器，离线运行。

### 1.4 配置高德 API Key（仅采集阶段需要）

P5 地理编码需要高德地图 Web Service API Key，用于将地址转换为经纬度并计算距离。

读取顺序（任选其一）：

1. 环境变量 `AMAP_API_KEY`
2. 项目根目录 `.env` 文件中的 `AMAP_API_KEY=...`
3. `config/geo.local.yaml`（从 `geo.local.yaml.example` 复制）

**安全规则**：

- 不得把真实 Key 写入 `.env.example`（该文件已入 Git 仓库）
- 不得把真实 Key 写入任何源码、配置模板或日志
- 三者均不存在时立即停止地理编码，不得使用默认 Key 或公共 Key
- `generate-report` 命令完全离线，不重新调用高德 API

### 1.5 初始化数据库

首次使用前需初始化 SQLite 数据库：

```
python -m boss_tool init-db
```

## 二、完整操作流程

以下是采集岗位数据并生成报告的完整流程，所有命令均通过 `python -m boss_tool <命令>` 调用。

### 步骤 1：初始化数据库

```
python -m boss_tool init-db
```

### 步骤 2：浏览器登录

```
python -m boss_tool browser-login
```

启动可见浏览器，用户手动完成登录/扫码/验证后，回到终端输入 `confirm`。
浏览器关闭或输入 `quit` 安全退出。

### 步骤 3：页面侦察（可选，用于保存测试夹具）

```
python -m boss_tool observe-page
```

启动可见浏览器，用户手动导航到需侦察的页面。
进入交互后可用命令：

- `status` — 输出会话与页面状态
- `inspect` — 检查当前页面类型
- `save-fixture` — 保存当前页面为测试夹具（需输入 SAVE 确认）
- `confirm` — 确认页面类型
- `quit` — 安全退出

### 步骤 4：采集当前搜索结果页与详情页

```
python -m boss_tool collect-current-page
```

启动可见浏览器，用户手动登录、手动搜索到目标岗位列表页。
进入交互后可用命令：

| 命令 | 说明 |
|------|------|
| `collect` | 采集当前搜索结果列表页（页面类型必须为 search_list） |
| `detail` | 仅采集用户已手动打开的当前岗位详情页（页面类型必须为 job_detail） |
| `status` | 输出会话与页面状态 |
| `quit` | 安全关闭 |

**采集流程**：

1. 在浏览器中手动搜索到目标岗位列表页
2. 回到终端输入 `collect`，采集当前列表页
3. 在浏览器中手动点击某个岗位卡片打开详情页
4. 回到终端输入 `detail`，采集当前详情页
5. 重复步骤 3-4 采集更多详情页
6. 输入 `quit` 退出

**安全规则**：

- 全程使用 Playwright 可见浏览器，不得后台静默运行
- `detail` 命令不自动点击岗位卡片、不自动导航、不自动切换到下一条岗位
- 遇到验证码、滑块、登录失败、403/429 等情况立即停止
- 不得实现反检测、绕过风控等功能
- 所有操作预算写入配置文件，不硬编码

### 步骤 5：生成 HTML 报告

```
python -m boss_tool generate-report --open
```

生成报告后自动在浏览器中打开（仅打开本地文件，不访问任何在线页面）。

## 三、generate-report 命令详解

### 3.1 基本用法

```
python -m boss_tool generate-report
```

默认从 `data/boss.db` 读取数据，输出到 `output/report.html`。

### 3.2 常用选项

| 选项 | 说明 | 示例 |
|------|------|------|
| `--output, -o` | 指定输出文件路径 | `--output D:\reports\job.html` |
| `--config-dir, -c` | 指定配置目录 | `--config-dir config` |
| `--db-path` | 指定数据库路径 | `--db-path D:\data\boss.db` |
| `--open` | 生成后自动用浏览器打开 | `--open` |

### 3.3 完整示例

```
python -m boss_tool generate-report --open
```

### 3.4 离线保证

- **完全离线**：不访问网络，不调用高德 API，不依赖 LLM 或机器学习
- **只读 SQLite**：使用 `mode=ro` 只读连接，不执行任何写操作
- **直接使用数据库已有数据**：直接读取 `job_detail.distance_meter` / `job_detail.within_3km`（P5 采集阶段计算并持久化的结果）
- **不重新计算距离**：不重新调用高德 API，不重新计算参考点坐标
- **不声称存在第二套锦园小区坐标常量**：参考地点名称仅用于报告展示，距离判断完全依赖数据库中已计算好的字段
- **距离字段缺失时显示"距离：未知"**：当岗位未采集详情页或地理编码失败导致 `distance_meter` 为空时，报告中显示"距离：未知"标签

### 3.5 安全保证

- **XSS 防护**：所有动态内容经 `html.escape` 转义
- **URL 校验**：所有链接经 `sanitize_url` 校验，仅允许 BOSS 直聘官方 HTTPS 链接
- **无外部资源**：内联 CSS/JS，不依赖 CDN、字体或图片
- **敏感数据脱敏**：手机号、邮箱替换为占位符

## 四、阅读报告

### 4.1 报告结构

报告分为四个分区，按推荐程度从高到低排列：

| 分区 | 颜色 | 含义 |
|------|------|------|
| 强烈推荐 | 绿色 | 适合 60 岁 + 3 公里内 + A/B 等级 |
| 可考虑 | 蓝色 | 适合 60 岁但距离/评分稍低 |
| 待人工确认 | 黄色 | 年龄未知或需进一步确认 |
| 不符合 | 红色 | 不适合 60 岁或明确超出 3 公里 |

### 4.2 排序规则

岗位按以下 7 级优先级排序（从高到低）：

1. 年龄适配（适合 > 需确认 > 未知 > 不适合）
2. 3 公里内（是 > 未知 > 否）
3. 推荐等级（A > B > C > D）
4. 总分（高 > 低）
5. 距离（近 > 远）
6. 招聘者活跃度（3 日内 > 本周 > 较久未活跃 > 不活跃 > 未知）
7. 采集时间（新 > 旧）

### 4.3 筛选功能

报告顶部提供以下筛选控件（均为内联 JS 实现，离线运行）：

| 控件 | 说明 |
|------|------|
| 关键词搜索 | 输入标题、公司、地点等关键词筛选岗位 |
| 分区筛选 | 下拉选择只显示某个分区（全部分区 / 强烈推荐 / 可考虑 / 待人工确认 / 不符合） |
| 重置 | 清除关键词与分区筛选条件 |

> 注：岗位分类、推荐等级、年龄适配、3 公里内、招聘者活跃、劳动强度警告等信息以标签形式显示在每个岗位卡片中，但不作为独立筛选下拉。劳动强度警告以警告区块显示在岗位卡片底部。

### 4.4 年龄适配说明

| 标签 | 含义 |
|------|------|
| 适合 60 岁 | 岗位无年龄限制或上限 ≥65 岁 |
| 需人工确认 | 年龄上限 60 岁（边界情况）或其他需确认情况 |
| 不适合 60 岁 | 年龄上限 <60 岁（如 45/50/55 岁以下） |
| 年龄未知 | 未提取到年龄要求，建议联系招聘者确认 |

### 4.5 招聘者活跃级别

按以下顺序从高到低排列：

1. 3 日内活跃（今日/昨日/3 日内/刚刚活跃）
2. 本周活跃（本周/7 日内/近一周）
3. 较久未活跃（其他活跃文本）
4. 不活跃
5. 未知

## 五、已知限制

1. **岗位实时性**：报告中的岗位可能已关闭或招满，需联系招聘者确认
2. **年龄判断**：基于文本提取，不保证 100% 准确，边界情况需人工确认
3. **距离计算**：依赖 P5 采集阶段的地理编码结果，部分地址可能无法解析，报告中显示"距离：未知"
4. **数据完整性**：部分岗位可能缺少详情页数据（仅列表页信息）
5. **单账号单浏览器**：不支持多账号或多浏览器并行采集
6. **不自动投递**：本工具不替用户自动投递简历或联系招聘者
7. **不承诺永不封号**：操作预算仅作为参考，不保证不触发平台风控

## 六、故障排查

### 6.1 数据库文件不存在

```
[ERROR] 数据库文件不存在: data/boss.db
```

解决：先执行 `python -m boss_tool init-db` 初始化数据库，并完成岗位采集。

### 6.2 配置加载失败

```
[WARN] 配置加载失败，降级使用默认常量
```

解决：`generate-report` 完全离线，配置加载失败不阻断报告生成，会使用默认常量（参考地点名称：杭州市拱墅区建国北路锦园小区，距离阈值：3 公里，候选人年龄：60 岁）。报告直接读取数据库中已计算好的 `distance_meter` / `within_3km` 字段，不重新调用高德 API，不声称存在第二套锦园小区坐标常量。如需自定义配置，请检查 `config/` 目录。

### 6.3 报告为空

```
[WARN] 数据库无岗位记录，将生成空报告
```

解决：先通过采集流程（`browser-login` → `collect-current-page` 中输入 `collect` / `detail`）将岗位数据写入数据库。

### 6.4 detail 命令提示页面类型不匹配

```
[ERROR] 页面类型不是 job_detail，拒绝采集详情页
```

解决：`detail` 命令仅采集用户已手动打开的当前岗位详情页。请在浏览器中手动点击岗位卡片打开详情页，再回到终端输入 `detail`。
