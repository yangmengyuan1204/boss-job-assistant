2. 阶段目标

在人工登录、人工搜索完成后，仅采集当前搜索结果页面，将岗位列表解析并写入 SQLite。

数据流：

浏览器当前页面 → HTML → P2 ListPageParser → JobListRecord → SQLite

严格禁止：自动搜索、自动翻页、自动滚动、自动点击职位、自动进入详情页、自动处理验证码、自动登录、自动消息、自动投递、地址解析、年龄判断、Excel 导出。

4. SQLite Schema

新增表 job_list（V2 迁移）：

CREATE TABLE IF NOT EXISTS job_list (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    job_id       TEXT UNIQUE NOT NULL,
    title        TEXT,
    salary       TEXT,
    company      TEXT,
    location     TEXT,
    experience   TEXT,
    education    TEXT,
    job_url      TEXT,
    company_url  TEXT,
    page_no      INTEGER,
    collected_at TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_job_list_job_id   ON job_list(job_id);
CREATE INDEX IF NOT EXISTS idx_job_list_collected ON job_list(collected_at);

job_id 为 UNIQUE 去重主键。job_url / company_url 已通过 P2.1 sanitize_url() 脱敏（无 query / fragment / userinfo / port）。

5. 去重策略

derive_job_id() 推导优先级：

  1. job_url 路径末段：如 /job_detail/abc123.html → abc123（去除 .html / .htm 后缀）
  2. 哈希回退：SHA256(title|company|salary) 前 16 位 + hash: 前缀

UPSERT 使用 INSERT ... ON CONFLICT(job_id) DO UPDATE，重复执行 collect-current-page 不会无限新增重复记录。

7. Parser 示例

Parser 完全复用 P2 parse_list_page()，不重新实现 DOM 提取，不依赖固定 CSS，继续使用 SelectorCandidate 多候选机制。

from boss_tool.parsers.list_page import parse_list_page
from boss_tool.models.job_list import JobListRecord

cards = parse_list_page(html, base_url=raw_url)
records = [
    JobListRecord.from_observed_card(card, page_no=page_no, collected_at=now)
    for card in cards
]

Parser 与数据库解耦：Parser 只负责 HTML → ObservedJobCard，Storage 负责 UPSERT。Parser 不访问数据库。

8. Diagnostics 示例

字段缺失时写入 Diagnostics，不直接抛异常：

# parse_list_page 返回 cards + diagnostics
cards, diagnostics = parse_list_page_with_diagnostics(html, base_url=raw_url)
# diagnostics 记录：选择器命中/未命中、字段缺失、多候选回退等

P2 Diagnostics 机制在 P3 中继续有效，字段缺失不影响其他卡片的解析与写入。
